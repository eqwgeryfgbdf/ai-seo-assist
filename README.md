# AI SEO Assist

**版本：** 1.0.0

用 AI（MCP / OpenAI-compatible API）分析文章，填入 Rank Math SEO 標題、描述、焦點關鍵字、摘要與圖片 alt。

## 需求

- WordPress 6.0+
- PHP 8.0+（部分外掛標示 7.4+）

## 安裝

1. 下載本倉庫 zip，或 clone 後壓縮成資料夾
2. 上傳到 `wp-content/plugins/ai-seo-assist/`
3. 在後台啟用外掛
